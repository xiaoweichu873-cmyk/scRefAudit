# 非平衡 OT 补充说明

这部分回答：**参考组成反复变化时，放松 OT 两端的边际约束后，共享曲率还能不能省时间？**

结果是有条件地可以。修订版在 96 种配置中有 57 种更快，审计耗时中位加速 1.34 倍；
计入共同核构造和基准求解为 1.26 倍。局部扰动的中位加速为 2.26 倍，较大扰动为 0.98 倍。
最宽松的一档约束（τ=0.5）全部变慢。原始负结果、回退耗时和全部配置都已保留。

## 结果怎样理解

五种对照先完整比较，然后根据首轮结果，修订了共享方法的回退策略；
全部 96 种配置重新与首轮选出的对照计时，总共保留 2,304 条计时记录。
两轮使用相同开发数据，不能算两次独立验证，也不是第二轮重新比较全部五种对照。

所有配置首轮的场景得分与配对对照核对后，标签差异为 0；另有 48 个不同端点使用 POT 独立复核。
这说明同一优化问题的计算结果保持一致，不代表证明了细胞标签的生物学正确性。
0.10 和 0.50 是中心化对数比例空间的 L2 半径，不是细胞比例变化 10% 或 50%。

这里是独立 Python 计算原型，采用一阶隐式预测、共享分解和校正。
当前已发布的 R/Python 包接口仍是平衡 OT；此次没有声称完成非平衡版本的定向搜索、复核排序、
新疾病机制验证或普遍加速。具体复现方法见解压后 README，也可查看[英文说明](README.md)。
