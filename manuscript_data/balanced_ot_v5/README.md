# Balanced optimal transport reproducibility package

[Download the full ZIP from the fixed Git commit](https://github.com/xiaoweichu873-cmyk/scRefAudit/archive/d728fff33f0ac58840f62e2d571764fef42477c3.zip). [Browse the same snapshot](https://github.com/xiaoweichu873-cmyk/scRefAudit/tree/d728fff33f0ac58840f62e2d571764fef42477c3).

The archive contains the exact prepared Kang and Hao inputs, the original research drivers, dependencies, comparator build materials, frozen per-cell outcomes, expected values, checksums and English/Chinese instructions for Figure 2B / Table 1 and Figure 5 of *Efficient reference composition sensitivity analysis for single-cell annotation*. The body of the archive is the content of a dedicated branch of this repository. Extract it and open README.md.

The package starts at the archived PCA embeddings. It separates redraws and reranking from new balanced OT fits and single-thread timing. Older code and worksheets use Figure 7B / Table 4 and Figure 4 for the same results. The public R and Python interfaces, workbooks and the exploratory KL-unbalanced supplement have their own descriptions in the main repository.
